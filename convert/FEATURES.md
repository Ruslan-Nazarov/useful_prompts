# Возможности и детали поведения convert

[English](FEATURES.en.md)

Этот каталог дополняет [SPEC.md](SPEC.md) и перечисляет 36 обязательных требований к поведению интерфейса и надёжности приложения. Реализуя приложение с помощью ИИ-агента, проверяйте каждый пункт в реальном взаимодействии с файлами.

---

## 1. Очередь документов и взаимодействие

| № | Деталь | Поведение и польза |
|---|---|---|
| 1 | **Поддержка Drag & Drop** | Перетаскивание поддерживаемых документов (.pdf, .djvu, .djv, .docx, .fb2, .epub) в любую область окна сразу добавляет их в очередь. |
| 2 | **Дедупликация файлов в очереди** | Повторное добавление уже находящегося в очереди файла игнорируется, не создавая дублирующих строк. |
| 3 | **Интеллектуальное автоопределение направления** | При добавлении `.docx` выбирается `DOCX → PDF`; при добавлении `.djvu` — `DjVu → PDF`; если пользователь предварительно выбрал `FB2 → DOCX` или `EPUB → DOCX`, выбор сохраняется. |
| 4 | **Живая миниатюра первой страницы** | При выборе строки таблицы справа немедленно отображается визуальный предпросмотр первой страницы документа (PDF, EPUB) или извлечённая обложка книги (FB2). |
| 5 | **Информационная карточка под превью** | Отображает имя файла, размер в удобных единицах (КБ / МБ), общее число страниц и габариты листа в типографских пунктах (pt). |
| 6 | **Защита от мутаций очереди во время работы** | Во время активной конвертации удаление строк из таблицы и кнопка «Очистить» блокируются, предотвращая рассинхронизацию индексов. |
| 7 | **Контекстное меню строки таблицы** | Правый клик по строке открывает меню: «Открыть результат», «Показать в папке», «Показать текст ошибки» (если произошёл сбой) и «Удалить из списка». |
| 8 | **Двойной клик по строке** | Открывает готовый файл во внешней программе по умолчанию. Если строка завершилась с ошибкой — открывает диалог с полным текстом ошибки. |
| 9 | **Индикация статусов цветом** | «✓ Готово» выделяется зелёным цветом `#059669`, «❌ Ошибка» — красным `#DC2626`, «Отменено» — оранжевым `#D97706`. |
| 10 | **Всплывающая подсказка (Tooltip) к статусу** | Наведение курсора на статус показывает путь к созданному файлу или подробный трейсбэк ошибки. |
| 11 | **Кнопка быстрого открытия результата** | После успешного завершения конвертации хотя бы одного файла внизу активируется кнопка «📂 Открыть результат». |
| 12 | **Кнопка показа в проводнике** | Позволяет в один клик открыть папку с результатами в проводнике Windows с выделением файла. |

## 2. Надежность конвертации и файловые гарантии

| № | Деталь | Поведение и польза |
|---|---|---|
| 13 | **Атомарная запись через Safe Write** | Результат конвертации сначала формируется во временной папке и лишь затем атомарно перемещается на место назначения. Частичные файлы исключены. |
| 14 | **Поддержка кросс-дискового перемещения** | Безопасная работа при несовпадении дисков (например, `%TEMP%` на диске `C:`, а папка сохранения на `D:`). Ошибка `WinError 17` перехватывается с прозрачной записью через локальный staging-файл. |
| 15 | **Неразрушающее автоименование (`_2`, `_3`)** | Если файл с таким именем уже существует в целевой папке, приложение не перезаписывает его вслепую, а подбирает следующий свободный индекс. |
| 16 | **Изоляция Word/DOCX воркера** | Конвертация DOCX выполняется в отдельном процессе. Сбои сложных документов не приводят к падению главного окна. |
| 17 | **Гарантированное прерывание по кнопке «Отменить»** | Отмена немедленно останавливает текущий файл, удаляет временные объекты и оставляет уже завершённые файлы нетронутыми. |
| 18 | **Проверка свободного места на диске** | Перед началом конвертации проверяется наличие свободного дискового пространства в целевой папке (минимум двукратный объём исходника). |
| 19 | **Резервный метод PDF → DjVu** | Если нативная утилита `pdf2djvu` выдаёт ошибку на нестандартном PDF, автоматически запускается резервный конвейер `PyMuPDF` + `c44` + `djvm`. |
| 20 | **Защита от защищённых паролем документов** | При обнаружении зашифрованного PDF пользователю выводится понятная подсказка о необходимости снять защиту, без бесконечного зависания. |

## 3. Инструменты PDF (PDF Tools)

| № | Деталь | Поведение и польза |
|---|---|---|
| 21 | **Асинхронное выполнение инструментов** | Склейка, нарезка, оптимизация и сборка картинок в PDF выполняются в фоновом потоке. Главный интерфейс не зависает. |
| 22 | **Сохранение закладок при склейке (Merge)** | При объединении нескольких документов структура оглавления и закладки исходных файлов объединяются в общее дерево. |
| 23 | **Гибкий парсинг диапазонов страниц** | Инструмент разделения понимает форматы `1-5, 8, 12-20`, `all`, корректирует обратный порядок (`5-1` → `1-5`) и удаляет дубли. |
| 24 | **Пропорциональное масштабирование фото в PDF** | Изображения в форматах A4 масштабируются с сохранением соотношения сторон, без сплющивания и искажения пропорций. |
| 25 | **Безопасная оптимизация растровых потоков** | При сжатии PDF заменяются только растровые потоки с обязательным обновлением фильтра `/DCTDecode` и цветового пространства. |
| 26 | **Сохранение прозрачности и альфа-каналов** | Картинки с мягкими масками (`SMask`) или альфа-каналами пропускаются при сжатии в JPEG, что исключает появление черных фонов вокруг прозрачных логотипов. |
| 27 | **Информативное окно итогов сжатия** | После сжатия выводится диалог с исходным размером, новым размером и точным процентом сэкономленного места. |

## 4. Телеметрия, интеграция и настройки

| № | Деталь | Поведение и польза |
|---|---|---|
| 28 | **Автономная SQLite база статистики** | Учёт всех действий ведётся локально в `%LOCALAPPDATA%\ConvertApp\stats.db` без отправки чего-либо в сеть. |
| 29 | **Счётчик сэкономленного дискового пространства** | На дашборде автоматически суммируется экономия байтов от сжатия и конвертаций. |
| 30 | **CLI канал телеметрии для лаунчера Albert** | Команда `Convert.exe --stats` выводит актуальный JSON-снимок метрик для внешних дашбордов. |
| 31 | **Экспорт отчёта в файл JSON** | Возможность в один клик экспортировать полную историю операций для аудита или переноса. |
| 32 | **Интеграция с контекстным меню в один клик** | Включение и отключение пункта в проводнике Windows прямо из вкладки настроек без прав администратора. |
| 33 | **Отсутствие дубликатов в контекстном меню** | Регистрация использует целевые ассоциации расширений (`SystemFileAssociations`), не засоряя глобальное меню проводника. |
| 34 | **Самодиагностика сборки (`--self-check`)** | Проверка работоспособности бинарных утилит тестовым циклом конвертации с формированием диагностического JSON-отчёта. |
| 35 | **Проброс Drag & Drop на командный файл (`start.cmd`)** | Перетаскивание файлов на ярлык или `start.cmd` передаёт параметры `%*` и открывает их в приложении. |
| 36 | **Чистая выгрузка при закрытии окна** | При закрытии окна активные задачи получают сигнал отмены, а пул потоков безопасно завершается с сохранением данных. |
