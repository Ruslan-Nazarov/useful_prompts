# convert — настольный конвертер документов и PDF-мастер

[English](README.en.md)

Комплект для создания собственного локального приложения для конвертации документов по мотивам `convert`:
направления DjVu ↔ PDF, PDF ↔ DOCX, DOCX → PDF, FB2 → DOCX/PDF, EPUB → DOCX/PDF, а также инструменты для PDF (склейка, нарезка, фото в PDF, сжатие). Приложение выполнено в стиле Windows 11 Fluent Design на PySide6 (Qt 6), работает полностью автономно без MS Office и интернета, включает локальную статистику и интеграцию с проводником Windows.

## Что понадобится

1. Компьютер под управлением Windows 10/11 x64, редактор кода и ИИ-агент с доступом к чтению/записи файлов и выполнению команд в терминале.
2. Python 3.12+ (зависимости `PySide6`, `pymupdf`, `python-docx`, `reportlab`, `pdf2docx` устанавливаются агентом).
3. Нативные консольные утилиты `ddjvu`, `c44`, `djvm` (из пакета DjVuLibre) и `pdf2djvu` (размещаются в папке `tools/`).
4. Интернет требуется только агенту для установки Python-пакетов; само создаваемое приложение работает **100% оффлайн**, не требует аккаунтов, внешних серверов и установленного пакета Microsoft Office.

## Как собрать приложение

1. Создайте пустую папку для проекта и скопируйте в неё этот комплект (файлы `PROMPT.md`, `SPEC.md`, `FEATURES.md`, `VISUAL.md` и папку `reference/`).
2. Откройте папку в редакторе с ИИ-агентом и отправьте ему текст из `PROMPT.md`.
3. Агент изучит техническое задание, составит план реализации и создаст кодовую базу:
   - ядро конвертации с поддержкой кросс-дискового безопасного перемещения;
   - изолированный процесс воркера для DOCX;
   - набор инструментов PyMuPDF (Merge, Split, Images-to-PDF, Compress);
   - графический интерфейс на PySide6;
   - базу данных SQLite и интеграцию с реестром проводника Windows.
4. Проверьте запуск приложения командой `python app.py` или через сгенерированный `start.cmd`.
5. Протестируйте конвертацию реальных документов и сверьте интерфейс с визуальной спецификацией [VISUAL.md](VISUAL.md).
6. Проверьте выполнение пунктов из каталога [FEATURES.md](FEATURES.md).
