# Промпт: создай настольный конвертер документов convert

[English](PROMPT.en.md)

Ты — опытный разработчик настольных приложений на Python и Qt 6 (PySide6). Создай в текущей пустой папке полноценное, автономное приложение для Windows в стиле Fluent Design под названием `convert`. Название всегда пиши `convert`, со строчной буквы.

Сначала полностью прочитай [SPEC.md](SPEC.md), [FEATURES.md](FEATURES.md), [VISUAL.md](VISUAL.md) и [reference/design-tokens.json](reference/design-tokens.json). Документ SPEC.md задаёт форматы, связи, архитектуру и хранение данных; FEATURES.md — 36 обязательных деталей взаимодействия и надёжности; VISUAL.md — точные цвета, шрифты, отступы и стиль интерфейса Windows 11. Не заменяй задание базовым прототипом на 1 экран: реализуй всю архитектуру от очереди и предпросмотра до инструментов PDF, телеметрии и контекстного меню.

## 1. Что должно уметь приложение

Приложение решает задачу быстрой, безопасной и автономной обработки документов без интернета и без установленного Microsoft Office.

Реализуй следующие ключевые модули:

1. **Очередь конвертации (8 направлений)**:
   - `DjVu → PDF` (растровые страницы через нативную утилиту `ddjvu`);
   - `PDF → DjVu` (перенос текста и оглавления через `pdf2djvu` с надёжным резервом `PyMuPDF` + `c44` + `djvm`);
   - `PDF → DOCX` (восстановление структуры, таблиц и картинок через `pdf2docx` в изолированном процессе);
   - `DOCX → PDF` (автономный экспорт через `python-docx` + `ReportLab` со шрифтами Segoe UI / Arial / Times);
   - `FB2 → DOCX` и `FB2 → PDF` (парсинг глав, сносок и раскодирование `base64` иллюстраций);
   - `EPUB → DOCX` и `EPUB → PDF` (парсинг манифеста OPF, глав XHTML и картинок).
2. **Интеллектуальная панель и предпросмотр**:
   - Автоматический выбор подходящего режима при перетаскивании файлов в очередь с сохранением осознанного выбора пользователя (например, `FB2 → DOCX`).
   - Панель живого предпросмотра: рендеринг первой страницы для PDF и EPUB; извлечение встроенной обложки для FB2; подробные метаданные (разрешение, число страниц, габариты в пунктах).
   - Выбор DPI (`150`, `300`, `400`, `600`) и профилей качества («Компактное», «Сбалансированное», «Максимальное»).
3. **Набор инструментов для PDF (PDF Tools)**:
   - **Склейка (Merge)** — объединение документов с сохранением дерева закладок/оглавления.
   - **Разделение (Split)** — постраничное деление или извлечение диапазона (`1-3, 5, 8-10`).
   - **Фотографии в PDF (Images to PDF)** — создание единого документа из картинок с сохранением пропорций (A4 или исходный размер).
   - **Сжатие и оптимизация (Compress)** — умная перепаковка XObject потоков в JPEG с обновлением заголовков `/Filter` и защитой картинок с альфа-масками.
4. **Атомарная файловая безопасность (Safe Write)**:
   - Никаких недописанных или повреждённых файлов в папке пользователя: результат формируется во временной директории и переносится атомарно.
   - Поддержка кросс-дисковых операций (Windows `WinError 17`): если целевая папка и временная директория находятся на разных дисках (`C:` и `D:`), перемещение выполняется через локальный staging-файл.
   - Защита от затирания файлов без подтверждения: генерация суффиксов `_2`, `_3` при совпадении имён.
5. **Локальная статистика и интеграция с Albert / ProcessDock**:
   - Автономный сбор метрик в базу SQLite (`%LOCALAPPDATA%\ConvertApp\stats.db`): число запусков, объём обработанных данных, сэкономленное место, журнал операций.
   - Канал телеметрии для лаунчера Albert: флаг командной строки `--stats` выводит актуальный JSON в `stdout`.
   - Автоматическая синхронизация файла отчёта `%LOCALAPPDATA%\ConvertApp\albert_telemetry.json` и фоновый сброс событий в `.bridge/telemetry` (ProcessDock).
6. **Интеграция с проводником Windows**:
   - Регистрация пунктов «Конвертировать документ (Convert)» и «Создать PDF из фото (Convert)» в ветке реестра текущего пользователя (`HKCU\Software\Classes\SystemFileAssociations`).
   - Работа без прав администратора и UAC; переключение в один клик из интерфейса.

## 2. Поведение и эргономика интерфейса

Выполни требования из [FEATURES.md](FEATURES.md) и [VISUAL.md](VISUAL.md):

- Интерфейс оформлен в стиле Windows 11 Fluent Design: чистый светлый фон `#F3F4F8`, белые карточки с радиусом 12 px, акцентный фиолетовый `#5D46E2`, чёткие индикаторы статуса.
- Все тяжёлые операции (конвертация, сжатие, склейка) выполняются в фоновых потоках `QThreadPool` / `QRunnable` с непрерывным обновлением прогресс-бара и текстового статуса. Главный поток Qt никогда не зависает.
- Очередь защищена от мутаций: во время выполнения конвертации удаление строк и очистка таблицы заблокированы.
- Кнопка «Отменить» немедленно прерывает процесс и очищает временные файлы.
- Контекстное меню таблицы и двойной клик позволяют мгновенно открыть готовый результат или изучить подробную ошибку.
- Наличие командного файла `start.cmd`, поддерживающего перетаскивание файлов на ярлык (`%*`).

## 3. Порядок реализации

1. **Архитектура ядра (`converter.py`, `worker.py`, `docx_export.py`, `ebook_export.py`)**:
   - Реализуй атомарную функцию `safe_write` с обработкой `WinError 17`.
   - Настрой изолированный worker для конвертации DOCX без Microsoft Office.
   - Напиши чистый парсер FB2 и EPUB с извлечением текста, структуры и иллюстраций.
2. **Модуль инструментов PDF (`pdf_tools.py`)**:
   - Реализуй `merge_pdfs`, `split_pdf`, `images_to_pdf` и безопасный `compress_pdf` через PyMuPDF.
3. **Модули данных (`stats_manager.py`, `telemetry.py`, `shell_integration.py`)**:
   - Настрой локальную базу SQLite, выгрузку JSON для лаунчера Albert и регистрацию в HKCU.
4. **Графический интерфейс (`gui_qt.py`)**:
   - Создай окно на PySide6 с навигационным сайдбаром (Конвертер, Инструменты PDF, Статистика).
   - Подключи `QThreadPool`, сигналы прогресса, Drag & Drop и превью обложек.
5. **Входная точка и портативная сборка (`app.py`, `build.py`, `start.cmd`)**:
   - Обеспечь поддержку аргументов командной строки (`--stats`, `--worker`, `--self-check`).
   - Настрой PyInstaller сборку со встроенными утилитами `ddjvu` и `pdf2djvu`.
   - Проверь все сценарии на реальных документах.
