# Приёмка DeskTools

[English](ACCEPTANCE.en.md)

Проводите проверки на вымышленных данных в отдельном профиле. В отчёте для каждого
A укажите результат, связанные F, команду/действия и наблюдение. Чётко различайте
автоматический тест движка, UI-проверку и настоящий ввод в целевое окно Windows.
Снимок с кнопкой не заменяет наблюдение результата.

| ID | Сценарий и ожидаемый результат | Требования |
|---|---|---|
| A01 | Запустить пустой профиль, пройти три раздела на 390/768/1440 px; проверить Tab, фокус, стрелки навигации, меню Esc и прокрутку без потери введённого. | F01 F02 |
| A02 | Собрать по README, проверить состав чистого переносимого архива. Запустить второй раз, скрыть и вернуть окно, проверить режим без трея, затем явный выход: один экземпляр и нет оставшихся обработчиков. | F03 F04 F40 |
| A03 | Сохранить шаблон/назначение, перезапустить; повредить основной JSON и отдельно удалить его; восстановить валидный backup с пояснением. | F06 F07 F08 |
| A04 | Сохранить большой набор кириллицы, превышающий 1 МиБ UTF-8, и имитировать отказ диска; оба файла, модель и черновик сохраняются. Импорт вымышленного PowerToys меняет только клавиатуру. | F06 F08 F09 |
| A05 | Записать Ctrl+Shift+F8, правый Ctrl и Пробел+В, включая autorepeat; уход из незавершённой записи сохраняет прежнее сочетание. | F10 F11 |
| A06 | Создать, изменить, отключить и удалить назначения; переключить типы с черновиками; отвергнуть дубль с переставленными модификаторами и неверный URL. | F12 F13 |
| A07 | В тестовом редакторе проверить exactMatch и приоритет длинного сочетания, однократный текст/URL, повтор клавиш, отсутствие рекурсии собственного ввода. | F14 F16 |

| A10 | Во время редактора сохранить настройки и проверить вложенные паузы: клавиатура, мышь и OCR не включаются раньше срока, явная пауза остаётся. | F05 F19 F35 |
| A11 | Проверить исходные кнопки и пять назначаемых источников мыши; удержание, key-up после паузы, дробные wheel-события, все виды действий, ошибки редактора. | F20 F21 F22 F23 F24 |
| A12 | Без устройства показать объяснение; проверить расчётом границы ночи и полуночи, простой/его сброс, ручное выключение и переполнение счётчика времени. | F25 F26 F27 F28 F29 |
| A13 | Только с 1532:006E считать исходную яркость, изменить обе зоны, подтвердить чтением и восстановить исходную в finally; ошибки пакетов отвергаются. | F25 F28 F29 |
| A14 | Вызвать OCR обеими Win+S; Win+Shift+S проходит Windows. Проверить отмену, выбор в обе стороны, микровыделение и монитор слева от основного. | F30 F31 |
| A15 | Распознать реальное тестовое изображение через Windows OCR; проверить строки, язык, абзац, пустой результат, копирование и открытие поля для правок. | F32 F34 |

Аппаратные проверки выполняются только на поддерживаемом устройстве. При
недоступном интерактивном рабочем столе пометьте зависимые проверки как
неподтверждённые. Запускайте независимые тесты и не подменяйте отсутствующий
Windows OCR ответом-заглушкой. Для разных DPI отдельно проверьте позицию caret,
границы popup и выделение между мониторами.
