# Спецификация DeskTools

[English](SPEC.en.md)

## Среда и границы

Настольное однопользовательское приложение для Windows 10/11. Русский интерфейс;
три основных раздела. Базовые функции локальные. Не добавляйте ИИ-чат, историю
буфера, аккаунты, запуск произвольных программ, правила для отдельных приложений
или обязательную синхронизацию. Открытие ссылок ограничено HTTP/HTTPS.

Предлагаются WinForms/.NET Framework 4.x, отдельные потоки глобальных низкоуровневых
перехватчиков, Windows OCR через скрытый PowerShell-процесс и прямой HID только
для поддерживаемого устройства. Архитектура может отличаться, поведение — нет.
Недоступность устройств и прав не должна завершать остальные функции.

## Настройки и операции

Один локальный JSON, версия схемы 1. Документируйте расположение и держите настройки
отдельно от исполняемого файла так, чтобы обновление их сохраняло. Минимальные поля:

| Группа | Поля |
|---|---|
| Общие | `version`, `remappingEnabled`, `ocrEnabled` |
| OCR | `ocrLanguage` (пустая строка — Windows), `ocrSingleParagraph`, `ocrShowResult` |
| Клавиатура | `mappings[]`: `name`, `enabled`, `source[]`, `kind`, `keys[]`, `text`, `url`, `exactMatch` |
| Мышь | `mouse.enabled`, `mouse.bindings[]`: `button`, `enabled`, `kind`, `keys[]`, `value` |
| Подсветка | `mouse.lighting`: `enabled`, `brightness`, `scheduleEnabled`, `offAt`, `onAt`, `idleMinutes` |
| Шаблоны | `templates[]`: `name`, `text` |

Используйте виртуальные коды Windows, последняя клавиша source — триггер.
Стороны Shift: 160/161, Ctrl: 162/163, Alt: 164/165, Win: 91/92.
Порядок удерживаемых клавиш не меняет идентичность сочетания; триггер меняет.
Клавиатурные виды действий: `keys`, `text`, `url`. Мышиные дополнительно:
`disabled`, `lighting`; кнопки: `middle`, `x1`, `x2`, `wheelUp`, `wheelDown`.
Отсутствующие секции старого файла получают безопасные значения: мышь и её
подсветка выключены, шаблоны пусты.

Лимиты: JSON до 1 МиБ в UTF-8; текст назначения до 4096 символов; не более
100 мышиных назначений, своё сочетание мыши до 16 различных клавиш; до 200
шаблонов, имя 1–100 символов, непустой текст 1–4096. Результат OCR редактируется
до 200 000 символов; непосредственная вставка до 10 000, для большего — копирование.
Пробельный шаблон не сохраняется. Невалидный URL и дубли включённых источников
отвергаются до применения.

Сначала проверьте весь кандидат и размер сериализации в байтах, затем запишите
временный файл, сбросьте запись и атомарно замените основной с резервной копией
предыдущей валидной версии. Ошибка не изменяет рабочую модель, исходный файл,
резервную копию и черновик редактора. При загрузке повреждённый основной файл
сохраняется отдельно, а валидная копия восстанавливается с пояснением.
При перезагрузке неверного JSON действует прежняя модель.

Импорт PowerToys — отдельное действие: глобальные ключи/сочетания, Unicode,
HTTP/HTTPS, без запуска программ и правил приложений. До замены запросите
подтверждение в интерфейсе. Сохраните остальные секции. В первый запуск допустимо
предложить импорт; демонстрационный профиль никогда не читает личный профиль.

## Клавиатура, мышь и общий жизненный цикл

Редакторы показывают итог действия и причину недоступного сохранения. Запись
не начинается при обычном вводе названия. Повтор удержанной клавиши не дублирует
записанное сочетание; уход из записи возвращает прежнее. Ctrl, Shift, Alt и Win
должны различаться по сторонам. Обработчик должен учитывать не только модификаторы,
но и удерживаемые обычные клавиши: Пробел+В допустимо.

Более длинные подходящие сочетания проверяются первыми, перед одиночной клавишей.
`exactMatch` запрещает дополнительные модификаторы. На время действия отпустите
исходные модификаторы сбалансированно и восстановите удерживаемые; исключите
повторную обработку собственного ввода. При удалении, отключении и замене
удержанного назначения завершите выходные нажатия и поглотите соответствующий
исходный key-up. Для общей выходной клавиши учитывайте все удерживающие источники.

Редактирование клавиатуры, мыши и шаблонов временно приостанавливает оба вида
переназначений и OCR. Общая пауза независима; вложенные приостановки снимаются
только после последнего владельца. Сохранение не включает службы раньше времени.
На паузе Ctrl+Alt+T не открывает список. Изменение общих настроек не ломает паузу.
Физическая активность доступна и при выключенных назначениях мыши.

Если работает PowerToys Keyboard Manager, объясните конфликт и приостановите
клавиатурные переназначения. Не завершайте чужие процессы. Горячие клавиши
Ctrl+Alt+Space и Ctrl+Alt+T регистрируются без автоповтора; конфликт показывается
понятно. Эти два сочетания зарезервированы в редакторе назначений. Win+S имеет
приоритет при включённом OCR; Win+Shift+S проходит в Windows.

## OCR, текст и шаблоны

Выделение охватывает виртуальный рабочий стол. Поддержите выбор в любом
направлении, отрицательные координаты, отмену и отказ от слишком маленькой области.
Не сохраняйте снимки надолго. Большие изображения уменьшайте до поддерживаемого
Windows OCR размера; для эталонного подхода — максимум 4000 px по стороне.
Отдельный процесс имеет тайм-аут 45 с, завершается по отмене; временные PNG/JSON
удаляются при успехе и ошибке. Закрытое приложение не публикует поздний результат.

Чистка пробелов сжимает табы, обычные и неразрывные пробелы внутри строки и
обрезает края. Склейка соединяет одиночные переводы строк пробелом, сохраняя
пустые строки между абзацами. Смена раскладки использует соответствие физических
позиций RU/EN; направление определяется преобладающими русскими/латинскими буквами.
Два поля редактируемы; пустые действия недоступны. Неуспешное копирование или
вставка не очищают ни одно поле.

Шаблоны создаются в отдельном редакторе из текстового раздела, сохраняются сразу
после явного сохранения, удаляются с подтверждением. Список вставки открывает
только Ctrl+Alt+T. Вверху подписанный поиск по имени и содержимому без учёта
регистра, затем строки с названием/фрагментом, полный предпросмотр и «Вставить».
Первая найденная строка выбирается; пустая выдача отключает вставку.

Для позиции используйте системный caret; если его нет — мышь. Ограничьте окно
рабочей областью выбранного монитора, при нехватке места снизу размещайте сверху.
Запомните исходное окно и системный фокус до открытия. Перед вставкой дождитесь
отпускания клавиш, верните окно и проверяйте цель между блоками текста.
Не разрывайте суррогатные пары. Переводы CRLF/LF/CR дают один текстовый перенос,
а не нажатие Enter. Буфер не заменяется. Отмена/закрытие прекращают оставшиеся
блоки; при остановке после частичного ввода прямо объясните это.
Проверка системного фокуса не доказывает неизменность DOM-поля внутри одного HWND.

## Подсветка и выпуск

По умолчанию подсветка выключена, яркость 60%, расписание выключено (23:00–08:00),
простой выключен. Пределы яркости 0–100%, простоя 0–240 минут; включённый
интервал с одинаковым началом/концом отвергается. Причина нулевой яркости:
ручное выключение, ночной интервал или простой. Время локальное, простой считает
только физические события и корректно переживает переполнение TickCount.

Поддерживается только DeathAdder Essential 1532:006E, зоны 4 (логотип) и 1
(колёсико), один зелёный цвет. Windows HID feature-report: report ID + 90 байт
полезной нагрузки. Используйте публичное описание протокола из SOURCES.md,
проверяйте команду/зону/статус/checksum и подтверждайте запись чтением.
Проверка расписания каждые 2 с, сверка устройства каждые 30 с; ошибки дают
повтор через 30 с и ручное переподключение. Отключение управления возвращает
дневную яркость. Другие устройства не пробуются записью наугад.

Дайте воспроизводимые команды сборки и тестов, переносимый запуск и второй
запуск одного экземпляра. Архив собирается в чистой staging-папке с нужными
ресурсами и OCR worker, без личных файлов. Обычный запуск не скачивает зависимости.
