# Создай DeskTools для Windows

[English](PROMPT.en.md)

Создай в текущей пустой папке работающее локальное настольное приложение
DeskTools. Оно объединяет глобальные переназначения клавиатуры и мыши,
управление поддерживаемой подсветкой, распознавание текста с экрана,
преобразования текста и быстрый выбор текстовых шаблонов.

Полностью прочитай SPEC.md, FEATURES.md, VISUAL.md, ACCEPTANCE.md, SOURCES.md,
`reference/design-tokens.json` и `demo-data.json` из этого комплекта. Составь
план, затем реализуй приложение. План, первый экран и рабочая отдельная функция
не завершают задание. В конце пройди все 40 требований и 20 сценариев приёмки.

## Приложение и взаимодействия

Оставь ровно три основных раздела: «Клавиатура», «Мышь», «Текст и OCR».
Все открываются в одном окне и сохраняют ввод при переключении. Служебное
меню содержит паузу, настройки, сворачивание и выход. Закрытие окна скрывает
приложение; явный выход снимает перехватчики и завершает фоновые операции.
Второй запуск показывает существующий экземпляр. Поддержи запуск из внешнего
менеджера процессов с отключением трея через PROCESSDOCK_NO_TRAY=1.

На экране клавиатуры пользователь добавляет, изменяет, отключает и удаляет
назначения. Редактор имеет два шага: исходная клавиша/сочетание и действие.
Запись включается явно и завершается первым отпусканием записанной клавиши;
можно записать Ctrl+Shift+F8 или Пробел+В. Различай стороны модификаторов.
Готовые медиакоманды, громкость, копирование, вставка и системные сочетания
не требуют лишних полей. Для своих клавиш, текста и HTTP/HTTPS-ссылки показывай
только подходящий параметр. При смене действия сохраняй отдельные черновики.

Переназначения должны работать глобально, сохранять сбалансированные down/up,
обычный повтор клавиш и правильное отпускание при смене настроек или паузе.
Текст и ссылка исполняются один раз на нажатие. Две исходные клавиши могут
удерживать одну выходную: отпускай её только после последнего источника.
При активном назначении Caps Lock защищай от случайного включения заглавных;
при явной паузе его обычная функция возвращается. Учитывай назначение клавиши
Ё/` на переключение языка в Windows при отображении действия.

В разделе мыши меняются колёсико, боковые кнопки и прокрутка; левая и правая
кнопки сохраняют обычную функцию. Поддержи команды, сочетания, текст, ссылки,
отключение кнопки и переключение подсветки. По умолчанию управление мышью
выключено; демонстрационные назначения — колёсико → Alt+Tab, боковая 5 →
воспроизведение/пауза. Предупреди о конфликте с Synapse, не завершая его.

Подсветка реализуется только для Razer DeathAdder Essential 1532:006E: зелёные
логотип и колёсико, общая яркость, ручное выключение, ночной интервал через
полночь и простой с возвратом при физической активности. Проверяй ответы HID
и обратное чтение. Остальные модели должны получать понятное сообщение;
не имитируй поддержку. Без мыши основное приложение продолжает работать.

Win+S запускает выделение области для Windows OCR. Используй перехватчик,
чтобы занятость системного RegisterHotKey не отключала эту функцию. Поддержи
обе Win, не перехватывай Win+Shift+S. Esc/правая кнопка отменяют выделение.
Работай на нескольких мониторах, включая отрицательные координаты. OCR
локальный, использует установленные языки Windows и сохраняет строки.
Результат копируется, доступен для правок и при желании открывается в разделе.

В текстовом разделе пользователь может получить текст из буфера, убрать лишние
пробелы, склеить строки с сохранением абзацев, исправить русскую/английскую
раскладку, отредактировать, скопировать и вставить результат в исходное поле.
Ctrl+Alt+Space запоминает исходное окно и открывает раздел. Ошибки не стирают ввод.

Создавать шаблоны можно через «Текст и OCR → Шаблоны…». Сам список для вставки
вызывается только Ctrl+Alt+T и появляется возле текстового курсора, а при
недоступной позиции — возле мыши, целиком в рабочей области монитора.
Нужны поиск по названию/тексту, фрагменты в списке и полный предпросмотр.
Стрелки выбирают, Enter/двойной щелчок/«Вставить» вставляют, Esc и уход фокуса
закрывают. Пустая библиотека объясняет, где добавить шаблон. При ошибке можно
повторить действие. Дождись отпускания клавиш перед возвратом в исходное поле;
уход из списка во время ожидания отменяет вставку. Сохраняй буфер обмена.
Unicode, emoji и абзацы передаются как текст без нажатия Enter для отправки формы.

## Надёжность и оформление

Раздели UI, данные, движки решений, службы перехватчиков, HID, OCR и вставку.
Перехватчики обслуживаются выделенными потоками и не выполняют OCR, запись
на диск или сетевые запросы. Служебные проверки не считаются физическим вводом.
Объедини временные приостановки: сохранение мыши или закрытие одного редактора
не должно включать обработчики, пока открыт другой редактор или включена пауза.

Настройки сохраняются атомарно с проверенной резервной копией. Проверяй
ограничения и размер UTF-8 до изменения файлов. Повреждённый или отсутствующий
основной файл восстанавливается из валидной копии; неверный новый файл не
заменяет работающие настройки. Импорт PowerToys меняет только клавиатуру и
сохраняет мышь, OCR и шаблоны. Примеры только вымышленные, в отдельном профиле;
личные настройки, ключи, история, снимки и диагностические данные не попадают в Git.

Следуй VISUAL.md и численным токенам: тёмная боковая навигация, светлая рабочая
область, белые плоские поверхности, прямоугольные кнопки, тёмно-оранжевое основное
действие, Segoe UI. На ширине менее 768 px навигация становится верхней;
длинные области прокручиваются. Проверь 390, 768 и 1440 px, Tab, фокус,
пустые состояния и ошибки без потери данных. Ресурсы создавай самостоятельно
или используй с подходящей лицензией; бинарные ресурсы исходника не приложены.

## Порядок реализации и результат

1. Настрой воспроизводимую сборку и запуск, три раздела, схему и сохранение.
2. Реализуй и проверь движки клавиатуры/мыши, редакторы и службы Windows.
3. Добавь OCR, текстовые действия, общую безопасную вставку и шаблоны.
4. Добавь поддержку подсветки с обработкой отсутствия оборудования.
5. Проверь приёмку, исправь найденные ошибки, подготовь переносимую сборку.

Предлагается C#/.NET Framework 4.x + WinForms и Windows PowerShell 5.1 для
Windows OCR. Другой стек допустим при том же поведении. Выдай README с точными
командами сборки, запуска, тестов, расположением настроек и обновлением без их
потери. Приложи таблицу F01–F40 и A01–A20 со способами проверки. Отдельно укажи
проверки настоящих перехватчиков, OCR, аппаратной подсветки и разных DPI.
Не объявляй результат готовым по кнопкам, скриншоту или тестам с заглушками.
