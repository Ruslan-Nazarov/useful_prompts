# Проверяемые возможности DeskTools

[English](FEATURES.en.md)

Для каждого ID приложите путь к реализации, выполненную проверку, результат и
существенное ограничение. «Есть кнопка» не подтверждает поведение. Все 40 пунктов
обязательны; аппаратные проверки могут оставаться неподтверждёнными при отсутствии
ровно поддерживаемого оборудования, с явным указанием этого в отчёте.

| ID | Требование |
|---|---|
| F01 | Три раздела в одном окне; переключение не теряет ввод и состояние. |
| F02 | Оформление по VISUAL.md, навигация сверху на узком окне, прокрутка, Tab и видимый фокус. |
| F03 | Один экземпляр; повторный запуск открывает существующий; закрытие скрывает, явный выход освобождает ресурсы. |
| F04 | PROCESSDOCK_NO_TRAY=1 отключает трей и всплывающие уведомления; запуск не требует внешнего менеджера. |
| F05 | Общая пауза и вложенные временные приостановки согласованы между клавиатурой, мышью, OCR и шаблонами. |
| F06 | Версионированные настройки валидируются и атомарно сохраняются с предварительным ограничением UTF-8 до 1 МиБ. |
| F07 | Валидная резервная копия восстанавливает повреждённый или отсутствующий основной файл; повреждённый файл сохраняется отдельно. |
| F08 | Ошибка загрузки/записи сохраняет предыдущую модель и введённые данные; старые настройки получают безопасные новые секции. |
| F09 | Подтверждаемый импорт PowerToys: клавиши, сочетания, текст и HTTP/HTTPS; сохраняет мышь, OCR и шаблоны. |
| F10 | Явная запись сочетаний с различением сторон модификаторов; завершение первым отпусканием; отмена без потери прежнего значения. |
| F11 | Сочетания с обычными удерживаемыми клавишами, включая Пробел+В; повторы записи не дублируют клавишу. |
| F12 | Клавиатурные действия: свои клавиши, готовые команды, текст, ссылки; редактор показывает только нужные поля и хранит черновики типов. |
| F13 | Создание, изменение, отключение, удаление; дубли включённых источников отвергаются независимо от порядка удерживаемых клавиш. |
| F14 | Приоритет длинных сочетаний перед одиночными; exactMatch исключает лишние модификаторы; собственный ввод не перехватывается повторно. |
| F15 | Down/up сбалансированы при паузе, замене, удалении и отключении; общий выход отпускается после последнего удерживающего источника. |
| F16 | Обычный повтор клавиш/медиакоманд; текст и URL однократны на нажатие; физические модификаторы восстанавливаются. |
| F17 | Защита от случайного Caps Lock только при его активном переназначении; пауза и отключение строки возвращают обычное поведение. |
| F18 | Подпись Ё/` отражает системное переключение языка/раскладки, не меняя настройки Windows. |
| F19 | Клавиатурный hook работает отдельно от UI; восстанавливается после снятия; конфликт PowerToys объясняется без завершения его процесса. |
| F20 | Мышь: колёсико, x1/x2, прокрутка; левая, правая и неназначенные кнопки сохраняют поведение. |
| F21 | Мышиные действия: команды, сочетания, текст, URL, отключение кнопки, переключение подсветки. |
| F22 | Мышь изначально выключена; демонстрационные назначения Alt+Tab/пауза; пояснение Synapse и отображение последней физической кнопки. |
| F23 | Удержанная кнопка не повторяет действие; wheel учитывает полные деления; отпускание поглощается даже после паузы/изменения. |
| F24 | Редактор мыши сохраняет черновики; дубликат, неверный URL и ошибка записи не закрывают его и не теряют текст. |
| F25 | Подсветка только 1532:006E, логотип/колёсико, общий зелёный уровень 0–100%, управление изначально выключено. |
| F26 | Локальный ночной интервал, включая полночь; выключение включительно, включение исключительно; одинаковые границы отвергаются. |
| F27 | Простой 0–240 минут, восстановление при физической активности; служебные probe-события не сбрасывают простой; корректный TickCount rollover. |
| F28 | Ручное выключение, переподключение, проверка после сна/возврата устройства; отключение управления возвращает дневную яркость. |
| F29 | HID-проверка команды/зоны/статуса/checksum, обратное чтение яркости, понятная ошибка и повтор; неподдерживаемая мышь не блокирует приложение. |
| F30 | Win+S через hook, обе Win, приоритет OCR; Win+Shift+S не перехватывается; недоступность RegisterHotKey не выключает OCR. |
| F31 | Выделение в любом направлении на нескольких мониторах с отрицательными координатами; Esc/правая кнопка отменяют; микровыделение не распознаётся. |
| F32 | Настоящий локальный Windows OCR, установленные языки, строки/необязательный абзац, копирование и необязательное открытие результата. |
| F33 | OCR worker ограничен временем, отменяется, чистит временные файлы и не публикует результат после завершения приложения. |
| F34 | Два редактируемых поля, ввод из буфера, чистка пробелов, склейка строк с абзацами и RU/EN-раскладка; пустые действия выключены. |
| F35 | Ctrl+Alt+Space запоминает цель; копирование и вставка результата сохраняют текст при ошибке и проверяют исходное окно/фокус. |
| F36 | CRUD шаблонов в текстовом разделе; до 200, имя до 100, текст до 4096; сохранение/ошибки без потери черновика. |
| F37 | Только Ctrl+Alt+T открывает список вставки у caret/мыши в рабочей области монитора; поиск по имени и содержимому. |
| F38 | Фрагменты, полный предпросмотр, стрелки, Enter/двойной щелчок/Вставить, Esc; пустая библиотека, пустой поиск и ошибка понятны. |
| F39 | Вставка шаблонов сохраняет буфер, ждёт отпускания клавиш; уход фокуса при ожидании отменяет; Unicode/emoji/абзацы и остановка при смене цели. |
| F40 | Воспроизводимая сборка, README и переносимый архив с нужными ресурсами; без личных настроек, секретов и диагностических данных. |
