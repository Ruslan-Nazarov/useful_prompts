# DeskTools — локальные инструменты Windows

[English](README.en.md)

Комплект задания для ИИ-агента: создайте своё настольное приложение с
переназначениями клавиатуры и мыши, локальным OCR, обработкой текста и вставкой
шаблонов по горячей клавише. Поддерживаемая подсветка Razer — отдельная возможность.
Интерфейс объединяет три раздела: «Клавиатура», «Мышь», «Текст и OCR».

| Файл | Назначение |
|---|---|
| [PROMPT.md](PROMPT.md) | Стартовое задание агенту, поведение и порядок реализации |
| [SPEC.md](SPEC.md) | Архитектурные границы, данные, сценарии и лимиты |
| [FEATURES.md](FEATURES.md) | 40 проверяемых требований F01–F40 |
| [VISUAL.md](VISUAL.md) | Оформление и адаптация интерфейса |
| [ACCEPTANCE.md](ACCEPTANCE.md) | 20 сценариев приёмки A01–A20 |
| [SOURCES.md](SOURCES.md) | Основа комплекта и сторонние ресурсы |
| [reference/design-tokens.json](reference/design-tokens.json) | Цвета, шрифты и размеры |
| [demo-data.json](demo-data.json) | Явно вымышленные настройки и шаблоны |

Все документы задания имеют английскую пару `.en.md`; пользовательские примеры
остаются на русском. Язык документации не меняет базовый русский интерфейс.

## Как собрать

1. Создайте пустую папку и скопируйте весь комплект, включая `reference/`.
2. Откройте её агенту с доступом к файлам и терминалу. Отправьте текст PROMPT.md.
3. Агент читает остальные документы и реализует приложение до приёмки.
4. Запустите приложение по его инструкции. Пройдите ACCEPTANCE.md и проверьте
   таблицу F01–F40: реализация, способ проверки, результат и ограничения.

Целевая система — Windows 10/11 с поддержкой Windows OCR и установленными языками
распознавания. Предлагаемый стек — C#/.NET Framework 4.x и WinForms; для сборки
нужны совместимый компилятор и Windows PowerShell 5.1. Другой стек допустим,
если реализует настоящие глобальные события Windows, а не только макет окна.
Обычная работа не требует интернета, ключей API, облака или отдельного драйвера.
Агент и установка его инструментов могут требовать интернет и оплату.

Демонстрационные данные загружаются отдельной явной командой в отдельный профиль.
Они не заменяют личные настройки. Текстовые шаблоны и назначения сохраняются
открытым текстом; не используйте общую папку проекта для секретов.

## Продолжение работы

> Сверь приложение с SPEC.md, FEATURES.md и VISUAL.md. Исправь пропуски и
> регрессии без потери настроек. Пройди ACCEPTANCE.md. Для каждого F/A укажи
> реализацию и фактическую проверку; отдели тест движка от живого ввода Windows.

Комплект задаёт поведение и оформление. Разные агенты могут реализовать их
по-разному. Проверка HID требует ровно поддерживаемой мыши; проверка глобального
ввода — интерактивного рабочего стола Windows. Отсутствие устройства или доступа
к рабочему столу должно быть отражено в отчёте, а не заменено успешной заглушкой.
