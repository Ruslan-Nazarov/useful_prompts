# Приложения из промптов

[English](README.en.md)

Здесь собраны задания для ИИ-агента, по которым можно построить свои приложения.
Каждый пример содержит основной промпт, требования, вымышленные данные и критерии
готовности. Результат зависит от агента и выбранного стека: один промпт не гарантирует
точную копию интерфейса из видео.

| Проект | Что собираем | Материалы |
|---|---|---|
| Papanda: личное время | Локальный дашборд задач, календаря, привычек и заметок | [Открыть комплект](papanda/README.md) |

Начните с README выбранного проекта. Для следующих выпусков добавляйте отдельные
папки по тому же принципу. Корень этой папки предназначен для отдельного GitHub-репозитория.
Каталог `.demo` — локальные материалы съёмки, в Git он не попадает.

Репозиторий: [useful_prompts](https://github.com/Ruslan-Nazarov/useful_prompts).
Промпты и документы доступны на русском и английском; ролик и демоданные — на русском.
Лицензию на новые промпты автор выбирает отдельно. Исходный код Papanda сохраняет свою
лицензию CC BY-NC 4.0 и указание автора.
