# useful_prompts

[English](README.en.md)

Авторские промпты для ИИ-агентов: создание приложений, автоматизация и полезные
инструменты. Каждый комплект содержит задание, требования и примеры для
самостоятельной реализации.

| Проект | Что собираем | Материалы |
|---|---|---|
| papanda — тайм-менеджмент | Приложение для тайм-менеджмента: задачи, календарь, привычки и заметки | [Русский](papanda/README.md) · [English](papanda/README.en.md) |

Откройте README нужного проекта и следуйте инструкции. Промпты и требования
доступны на русском и английском. Пример данных для papanda — на русском;
все его персонажи, записи и показатели вымышлены.

Результат зависит от агента и выбранного стека. Комплект задаёт поведение
приложения, но не гарантирует точного повторения интерфейса из примера.

В комплекте papanda: [полное ТЗ](papanda/SPEC.md), [64 детали поведения](papanda/FEATURES.md)
и [визуальная спецификация](papanda/VISUAL.md) с точными значениями оформления.
