# useful_prompts

[English](README.en.md)

Авторские промпты для ИИ-агентов: создание приложений, автоматизация и полезные
инструменты. Каждый комплект содержит задание, требования и примеры для
самостоятельной реализации.

| Проект | Что собираем | Материалы |
|---|---|---|
| papanda — тайм-менеджмент | Приложение для тайм-менеджмента: задачи, календарь, привычки и заметки | [Русский](papanda/README.md) · [English](papanda/README.en.md) |
| papanda — изучение языков | Разбор предложений, словарь, повторение, мастерская и встроенная книга | [Русский](papanda-language/README.md) · [English](papanda-language/README.en.md) |

Откройте README нужного проекта и следуйте инструкции. Промпты и требования
доступны на русском и английском. Примеры пользовательских данных — на русском;
все их персонажи, записи и показатели вымышлены. Учебные материалы сохраняют
исходный язык и условия использования.

Результат зависит от агента и выбранного стека. Комплект задаёт поведение
приложения, но не гарантирует точного повторения интерфейса из примера.

В комплекте тайм-менеджмента: [полное ТЗ](papanda/SPEC.md), [64 детали поведения](papanda/FEATURES.md)
и [визуальная спецификация](papanda/VISUAL.md) с точными значениями оформления.

В языковом комплекте: [полное ТЗ](papanda-language/SPEC.md),
[96 требований](papanda-language/FEATURES.md), [36 сценариев приёмки](papanda-language/ACCEPTANCE.md),
[протокол ИИ](papanda-language/AI.md), [развёртывание](papanda-language/DEPLOYMENT.md)
и [разработка](papanda-language/DEVELOPMENT.md). Приложены автономные учебные данные
и авторская книга с [отдельными условиями использования](papanda-language/SOURCES.md).
