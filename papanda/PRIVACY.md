# Что входит в демо и публикацию

[English](PRIVACY.en.md)

Все записи в `demo-data.json` написаны с нуля. Алексей, Марина, Дима, проект
«Атлас», встречи, привычки, заметки и показатели экспериментов вымышлены.
Личная база автора не используется даже как образец.

Генератор берёт из исходной Papanda только `fastapi_app` с разрешёнными расширениями,
номер версии из истории, зависимости и файл лицензии. Он не копирует `data`,
`.env`, Git, журналы, токены, резервные копии и шаблоны аналитики. Внутри демо
настройки путей принудительно указывают на новый каталог. При несовпадении путей
запуск останавливается.
Из окружения родительского процесса передаются только системные параметры запуска.
Ключи API не наследуются; маршруты голоса и Google Calendar в демо заблокированы.

В копии интерфейса для съёмки убрана персональная авторская строка подвала.
История изменений заменена короткой демонстрационной записью. Внешние шрифты
не запрашиваются. Исходное приложение и его подписи не меняются.
Файл лицензии сохраняется в локальном снимке исходников; он не входит в публичный
комплект промптов. Не снимайте редактор с локальными исходниками, лицензией,
абсолютными путями или личными вкладками — снимайте окно демо в отдельном профиле.

Для публикации используйте экспорт с фиксированным списком файлов:

```powershell
python -B papanda/demo.py export
```

Из корня исходной Papanda:

```powershell
.\.venv\Scripts\python.exe -B prompt-library/papanda/demo.py export
```

Получится `prompt-library/public-kit.zip`: инструкции, промпт, требования,
сценарий, вымышленные данные и скрипты запуска. Распакуйте его в пустую папку
нового репозитория. Баз, снимков приложения, локальных путей из манифеста и `.demo`
в архиве нет. Обычный `.gitignore` также исключает эти файлы, но экспорт делает
состав публикации явным.

После подготовки `demo.py check` проверяет ссылки и целостность SQLite,
число записей, отсутствие пользователей и подключений календаря, а также открытие
основных страниц. Это не проверка личных вкладок, уведомлений или рабочего стола:
они находятся вне приложения.
