# useful_prompts

[Русский](README.md)

Original prompts for AI agents to build apps, automate workflows, and create
useful tools. Each kit includes a prompt, requirements, and examples for an
independent implementation.

| Project | What you build | Materials |
|---|---|---|
| papanda — time management | A time management app with tasks, a calendar, habits, and notes | [English](papanda/README.en.md) · [Русский](papanda/README.md) |
| papanda — language learning | Sentence breakdown, vocabulary, spaced repetition, workspace, and reader | [English](papanda-language/README.en.md) · [Русский](papanda-language/README.md) |
| DeskTools — Windows tools | Keyboard and mouse remapping, OCR, text templates, and Razer Chroma lighting | [English](desktools/README.en.md) · [Русский](desktools/README.md) |
| convert — document converter | Offline PDF, DjVu, DOCX, FB2, EPUB converter & PDF master with Fluent UI and telemetry | [English](convert/README.en.md) · [Русский](convert/README.md) |

Open the project's README and follow its instructions. Prompts and requirements
are available in Russian and English. Sample user data is in Russian;
all characters, records, and metrics are fictional. Learning materials preserve
their original language and terms of use. The convert kit is fully self-contained and ready for fresh deployment.

Results depend on the agent and technology stack. Each kit specifies application
behavior but does not guarantee an exact copy of a reference interface.

The time management kit includes a [full specification](papanda/SPEC.en.md),
[64 interaction details](papanda/FEATURES.en.md), and a [visual specification](papanda/VISUAL.en.md)
with exact styling values.

The language learning kit includes a [full specification](papanda-language/SPEC.en.md),
[96 requirements](papanda-language/FEATURES.en.md), [36 acceptance scenarios](papanda-language/ACCEPTANCE.en.md),
an [AI protocol](papanda-language/AI.en.md), [deployment guide](papanda-language/DEPLOYMENT.en.md),
and [development instructions](papanda-language/DEVELOPMENT.en.md). Self-contained learning data
and an original book with [separate terms of use](papanda-language/SOURCES.en.md) are included.

The DeskTools kit includes a [full specification](desktools/SPEC.en.md),
[40 requirements](desktools/FEATURES.en.md), [20 acceptance scenarios](desktools/ACCEPTANCE.en.md),
a [visual specification](desktools/VISUAL.en.md), and fictional verification settings.

The convert kit includes a [prompt](convert/PROMPT.en.md), [full specification](convert/SPEC.en.md),
[36 interaction details](convert/FEATURES.en.md), [visual specification](convert/VISUAL.en.md),
and [design tokens](convert/reference/design-tokens.json).
