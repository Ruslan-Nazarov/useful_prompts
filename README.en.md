# useful_prompts

[Русский](README.md)

Original prompts for AI agents to build apps, automate workflows, and create
useful tools. Each kit includes a prompt, requirements, and examples for an
independent implementation.

| Project | What you build | Materials |
|---|---|---|
| papanda — time management | A time management app with tasks, a calendar, habits, and notes | [English](papanda/README.en.md) · [Русский](papanda/README.md) |
| papanda — language learning | Sentence analysis, dictionary, review, workshop and an embedded book | [English](papanda-language/README.en.md) · [Русский](papanda-language/README.md) |

Open the project's README and follow its instructions. Prompts and requirements
are available in Russian and English. Sample user data is in Russian;
all its characters, records, and metrics are fictional. Learning materials retain
their original language and usage terms.

Results depend on the agent and technology stack. Each kit specifies application
behavior but does not guarantee an exact copy of a reference interface.

The time management kit includes a [full specification](papanda/SPEC.en.md),
[64 interaction details](papanda/FEATURES.en.md), and a [visual specification](papanda/VISUAL.en.md)
with exact styling values.

The language learning kit includes a [full specification](papanda-language/SPEC.en.md),
[96 requirements](papanda-language/FEATURES.en.md), [36 acceptance scenarios](papanda-language/ACCEPTANCE.en.md),
an [AI protocol](papanda-language/AI.en.md), [deployment](papanda-language/DEPLOYMENT.en.md)
and [development](papanda-language/DEVELOPMENT.en.md) guides. Offline learning
datasets and the author's book are supplied with [separate source notices](papanda-language/SOURCES.en.md).
