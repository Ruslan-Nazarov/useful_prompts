# Useful prompts

[Русский](README.md)

Original prompts for AI agents to build apps, automate workflows, and create useful
tools. Each project includes a main prompt, requirements, examples, and acceptance
checks. Results depend on the agent and technology stack: a prompt does not
guarantee an exact copy of the interface shown in a video.

| Project | What you build | Materials |
|---|---|---|
| Papanda: personal time | A local dashboard for tasks, a calendar, habits, and notes | [Open the kit](papanda/README.en.md) |

Start with the project's README. Add a separate folder for each future project.
This directory is intended to be the root of its own GitHub repository.
Repository: [useful_prompts](https://github.com/Ruslan-Nazarov/useful_prompts).
The `.demo` directory contains local filming materials and is excluded from Git.

Prompts and documentation are available in Russian and English. The video is in
Russian, and its fictional demo data intentionally remains in Russian.

Choose a license for the new prompts before assigning reuse terms. The original
Papanda source code retains its CC BY-NC 4.0 license and attribution requirements.
