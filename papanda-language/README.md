# papanda — приложение для изучения языков

[English](README.en.md)

Полный комплект задания для ИИ-агента, который создаёт собственное приложение
по мотивам papanda. В центре — понимание структуры предложения: от целой мысли
к сказуемому, подлежащему и уточняющим членам. Словарь и повторение помогают
этой практике, а встроенная авторская книга связывает правило с упражнением.

Это комплект для разработки, а не готовое приложение. Исходная реализация:
[papanda-language-app](https://github.com/Ruslan-Nazarov/papanda-language-app).
Зафиксированное поведение: локальная версия 1.3.0 от 21 октября 2026 года.

## Как собрать своё приложение

1. Создайте пустую папку. Скопируйте **весь** каталог `papanda-language`, включая
   `reference/` и `tools/`, например в подпапку `assignment/`.
2. Проверьте комплект: `node assignment/tools/validate-kit.cjs`.
3. Откройте проект агенту с доступом к файлам и терминалу. Отправьте полный текст
   [PROMPT.md](PROMPT.md), указав, где лежит комплект.
4. Агент читает материалы, составляет план и пишет приложение до прохождения
   приёмки. План и первый экран не завершают задание.
5. Запустите приложение по инструкции агента. Сначала проверьте автономную версию,
   затем при необходимости настройте собственный ИИ-прокси и соберите APK.
6. Потребуйте отчёт по каждому ID из FEATURES.md и каждому сценарию ACCEPTANCE.md.

Нужны компьютер, Node.js 22+, npm и агент, способный запускать команды.
Для Android удобна облачная сборка EAS; для локальной нативной сборки нужны
Android SDK/JDK, для локальной iOS — macOS/Xcode. Ключи ИИ, Cloudflare и аккаунт
Expo нужны только для соответствующих сетевых функций/сборок. Интернет требуется
для агента и установки пакетов. Основные учебные режимы и книга работают автономно.

## Продолжение и исправление

> Сверь приложение с SPEC.md, DATA.md, AI.md и VISUAL.md. Обнови таблицу каждого
> пункта FEATURES.md: реализация, проверка, результат. Исправь пропуски, затем
> выполни ACCEPTANCE.md. Сохрани данные и работающие функции. Не принимай
> наличие кнопки, успешный экспорт JS или ответы ИИ-заглушки за проверенный APK.

> Сверь интерфейс с VISUAL.md и reference/design-tokens.json. Проверь ширину
> 320, 390, 768 и 1440, длинные слова, семь языков, клавиатуру, системные отступы,
> таблицы книги, раскрытие предложения и закрытие модальных окон.

## Границы

Комплект не обещает идентичный результат у разных агентов и стеков.
Учебные данные и ИИ-разборы требуют проверки; наличие корректной ссылки на книгу
не доказывает правильность объяснения. Автоматическая проверка комплекта проверяет
его файлы, а не существование и качество ещё не написанного приложения.
Книга поставляется с отдельной исходной лицензией; см. SOURCES.md.
